## Come aprire la Chat di Copilot su Visual Studio / How to Open Copilot Chat in Visual Studio

### 🇮🇹 Italiano

Per aprire la chat con GitHub Copilot in Visual Studio:

1. **Menu View**: Vai su `View` → `GitHub Copilot Chat`
2. **Barra di ricerca**: Premi `Ctrl+Q` e cerca "Copilot Chat"
3. **Scorciatoia da tastiera**: Controlla le impostazioni della tastiera per la scorciatoia assegnata

**Requisiti**:
- Visual Studio 2022 versione 17.6 o superiore
- Estensione GitHub Copilot installata
- Account GitHub con abbonamento Copilot attivo

### 🇬🇧 English

To open GitHub Copilot Chat in Visual Studio:

1. **View Menu**: Go to `View` → `GitHub Copilot Chat`
2. **Search bar**: Press `Ctrl+Q` and search for "Copilot Chat"
3. **Keyboard shortcut**: Check your keyboard settings for the assigned shortcut

**Requirements**:
- Visual Studio 2022 version 17.6 or higher
- GitHub Copilot extension installed
- GitHub account with active Copilot subscription
